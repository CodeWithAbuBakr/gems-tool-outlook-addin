# GEMS Tool – Global Entity Management System - Change Request Tool

## Overview
GEMS Tool is an Outlook Add-in designed to streamline the process of managing and submitting changes for global entities. It provides a user-friendly interface to handle updates such as:
- Director/Officer updates
- Ownership transfers
- Address changes
- Legal form modifications
- Status changes
- Name changes
- Country counsel updates

All directly from within Outlook.

## Features
- **Change Selection:** Choose the type of entity change you want to submit.
- **Guided Forms:** Step-by-step input forms ensure data accuracy and completeness.
- **Document Upload:** Attach supporting documents directly within the add-in.
- **Automated Summary:** Automatically generates a structured summary of the change request.
- **Email Submission:** Submits the request and all supporting evidence via Outlook email.
- **Compliance Support:** Ensures all changes are properly documented and sent to the right recipients.

## Benefits
- Simplifies entity management
- Reduces manual effort
- Improves accuracy and compliance
- Provides a centralized, Outlook-integrated solution

## Installation
1. Open Outlook.
2. Go to **Get Add-ins** → **My Add-ins** → **Add a custom add-in**.
3. Upload the GEMS Tool manifest file (`manifest.xml`).
4. Restart Outlook.
5. You’ll find GEMS Tool under the Outlook ribbon or side panel.

## Usage
1. Launch the GEMS Tool from the Outlook ribbon.
2. Select the type of change you need to submit.
3. Fill in the guided form with required details.
4. Upload any supporting documents.
5. Review and submit the change request.
6. The tool will generate an email with all necessary details and attachments.
